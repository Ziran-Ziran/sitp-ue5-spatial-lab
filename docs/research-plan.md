# SITP 研究计划

研究问题：在 UE5 可控仿真中，带置信度与时序的空间语义能否提高目标搜索和路径规划的可靠性？实验平台用于控制变量、获取独立真值和重复失败条件，不把仿真成绩自动推广到现实。

阶段一固定场景、代理尺寸、目标、输入许可和按场景划分，建立引擎 NavMesh/oracle 与估计几何规划对照。阶段二加入语义识别与实体关系；比较几何-only、语义、语义+时序/置信度，保持观测和路线预算一致。阶段三逐项增加低光、重复纹理、动态遮挡和深度失效，记录退化曲线与失败原因。

主指标：导航成功、碰撞、路径效率、语义目标正确率、重规划与延迟；辅助指标：跟踪覆盖、定位误差和地图质量。按预注册条件汇总全部回合，不挑最好的路线或按真值调参。

本次分拆没有新增语义模型、规划器或真实导航结果。已有几何工具是基础设施；优先实现一个受控语义目标任务，再扩展场景复杂度。
